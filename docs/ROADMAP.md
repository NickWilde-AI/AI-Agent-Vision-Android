# VisionAgent Android 产品文档

本文档描述 VisionAgent Android 的产品定位、用户场景、能力边界、版本规划和上线目标。

## 产品定位

VisionAgent Android 是一个面向普通用户的 AI 手机助手。它通过屏幕理解和无障碍操作帮助用户完成手机上的重复性、步骤性任务。

产品目标不是替用户失控地操作手机，而是在用户授权和确认下，把复杂手机操作变成可理解、可控制、可中止的智能流程。

## 产品愿景

让用户可以用自然语言完成手机任务：

```text
打开设置，把亮度调高一点
帮我打开微信，给 Nick 写一段消息草稿
帮我搜索附近的咖啡店
打开浏览器查一下今天的天气
```

VisionAgent 应该像一个谨慎的手机助理：

- 能看懂当前屏幕。
- 能理解用户目标。
- 能一步一步操作。
- 不确定时会停下来。
- 高风险动作会请求确认。
- 做错时能解释和复盘。

## 目标用户

### 普通用户

需求：

- 用自然语言完成常见手机操作。
- 减少重复点击。
- 简化复杂设置路径。

典型场景：

- 打开 App。
- 调整系统设置。
- 搜索内容。
- 填写草稿。
- 导航到目标页面。

### 低频或不熟悉手机操作的用户

需求：

- 不记得设置入口。
- 不熟悉复杂 App 页面。
- 希望助手一步步带到目标页面。

典型场景：

- 找到 Wi-Fi 设置。
- 打开蓝牙设置。
- 调整亮度。
- 查找联系人。

### 高阶用户

需求：

- 自动化重复流程。
- 快速跳转多步骤页面。
- 记录失败并优化策略。

典型场景：

- 浏览器搜索。
- App 内查找。
- 多步骤信息录入。

## 核心价值

1. 降低手机操作成本。
2. 把多步骤任务变成一句话。
3. 对复杂 App 提供安全辅助。
4. 对高风险动作保留用户最终控制权。
5. 通过失败记忆持续提升成功率。

## 产品原则

### 用户掌控

用户必须能随时取消、暂停、确认或拒绝任务。

### 安全优先

以下动作不得默认自动执行：

- 发送消息
- 支付
- 下单
- 删除
- 转账
- 提交订单
- 不可逆确认

### 透明可解释

Agent 应展示：

- 当前任务目标。
- 当前所在 App。
- 下一步动作。
- 为什么需要用户确认。
- 失败原因。

### 渐进式自动化

先做低风险任务，再做复杂 App 辅助，不直接追求全自动跨 App 操作。

## MVP 范围

MVP 目标：让用户能稳定完成低风险任务，并验证 Android Agent 主链路。

### MVP 包含

- 打开 App。
- 返回、Home、最近任务。
- 点击和滑动。
- 文本输入。
- 系统设置跳转。
- 浏览器搜索。
- 微信草稿输入。
- 高风险动作拦截。
- 基础执行进度展示。

### MVP 不包含

- 自动发送消息。
- 自动支付。
- 自动下单。
- 自动删除。
- 绕过第三方 App 风控。
- 完全离线视觉理解。

## 关键用户流程

### 打开 App

```text
用户：打开微信
Agent：识别目标 App
Agent：启动微信
Agent：确认当前包名
Agent：结束任务
```

成功标准：

- 目标 App 被打开。
- 没有多余点击。
- 打不开时给出原因。

### 系统设置

```text
用户：打开蓝牙设置
Agent：识别系统设置任务
Agent：打开对应设置页
Agent：等待用户自行确认开关
```

成功标准：

- 能进入目标设置页。
- 不自动切换敏感系统开关。

### 浏览器搜索

```text
用户：搜索今天北京天气
Agent：打开浏览器
Agent：聚焦地址栏或搜索框
Agent：输入搜索词
Agent：提交搜索
```

成功标准：

- 搜索结果页打开。
- 不提交登录、支付、隐私表单。

### 微信草稿

```text
用户：给 Nick 发微信说我晚点到
Agent：打开微信
Agent：搜索 Nick
Agent：进入聊天页
Agent：输入“我晚点到”
Agent：停止，等待用户手动发送
```

成功标准：

- 草稿已进入输入框。
- 发送按钮没有被点击。
- 用户知道下一步需要自己确认。

## 产品能力分层

### L1：系统级基础操作

稳定性目标最高。

- 打开 App
- 返回
- Home
- 最近任务
- 滑动
- 音量
- 设置页跳转

### L2：页面级辅助

需要 UI 树和视觉模型协作。

- 点击搜索框
- 输入内容
- 页面滚动
- 选择列表项
- 打开详情页

### L3：App 专项任务

必须有 App 策略。

- 微信草稿
- 浏览器搜索
- 系统设置
- 联系人查找
- 地图搜索

### L4：高风险流程

只能辅助，不自动完成最终动作。

- 发送
- 支付
- 下单
- 删除
- 转账

## 版本规划

### v0.1：Agent 基座

目标：验证主链路。

能力：

- 无障碍服务。
- 屏幕截图。
- UI 树提取。
- 云端视觉模型。
- 基础动作执行。
- 多轮反馈循环。

状态：已基本完成。

### v0.2：安全可控 Agent

目标：降低误操作风险。

能力：

- 本地 RAG 策略库。
- PlannerAgent。
- ReflectionAgent。
- ActionGuard。
- 微信草稿模式。
- 高风险动作拦截。

状态：基础版已完成。

### v0.3：可观测 Agent

目标：失败可复盘。

能力：

- AgentTrace。
- 每轮截图状态记录。
- UI 树摘要记录。
- 模型输出记录。
- 执行结果记录。
- 失败样本导出。

状态：待开发。

### v0.4：产品交互

目标：让普通用户能理解和控制 Agent。

能力：

- 任务运行面板。
- 暂停、取消、继续。
- 高风险确认弹窗。
- 权限诊断。
- 失败原因展示。

状态：待开发。

### v0.5：App 策略库

目标：提高真实 App 成功率。

能力：

- `WechatStrategy`
- `BrowserStrategy`
- `SettingsStrategy`
- `ContactsStrategy`
- `MapSearchStrategy`

状态：待开发。

### v0.6：记忆系统

目标：让 Agent 从失败中学习。

能力：

- Room 持久化 RAG。
- 失败样本检索。
- 用户偏好记忆。
- 相似任务召回。

状态：待开发。

### v1.0：公开可用版本

目标：可面向真实用户测试。

上线条件：

- 核心低风险任务稳定。
- 高风险确认机制完整。
- 至少覆盖 3 个 App 策略。
- 有失败日志和问题反馈机制。
- 权限流程清晰。
- 文档完整。

## 成功指标

### 功能指标

- 低风险任务成功率。
- App 打开成功率。
- 输入框定位成功率。
- 页面跳转成功率。

### 安全指标

- 高风险动作拦截率。
- 误点击次数。
- 未确认最终动作次数。

### 可观测指标

- 截图可用率。
- UI 树可用率。
- 失败样本完整率。
- 平均任务轮数。

### 用户体验指标

- 用户是否理解下一步动作。
- 用户是否能及时取消任务。
- 失败原因是否明确。

## 当前优先级

P0：

1. AgentTrace 失败日志。
2. 高风险确认弹窗。
3. 微信草稿状态机。

P1：

1. BrowserStrategy。
2. SettingsStrategy。
3. RAG 持久化。

P2：

1. 本地 OCR。
2. 本地 VLM。
3. 语音输入。

## 非目标

当前阶段不做：

- 绕过 App 风控。
- 自动发送微信。
- 自动支付。
- 自动下单。
- 自动删除数据。
- 后台静默控制手机。

这些能力即使技术上部分可行，也不符合产品安全边界。
