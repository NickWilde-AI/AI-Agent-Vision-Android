# L1 基础能力清单

L1 是 VisionAgent 的手机基础能力底座，目标是把低风险、可恢复、可验证的系统级动作做扎实。L1 不追求复杂页面理解，也不替用户完成不可逆确认动作。

## L1 定义

L1 能力需要同时满足：

- 单步或近似单步完成。
- 失败可恢复，不会造成明显损失。
- 可通过包名、系统 API、无障碍全局动作或设置入口验证。
- 不涉及支付、发送、删除、配对确认、账号切换等高风险结果。

## 当前已实现

| 类别 | 能力 | 执行方式 | 边界 |
| --- | --- | --- | --- |
| 系统导航 | 返回、Home、最近任务、关闭键盘 | 无障碍全局动作 | 不判断业务页面是否完成 |
| 系统遮罩 | 打开通知栏、打开快捷设置、关闭通知栏/控制中心 | 无障碍全局动作 | 不点击通知内容 |
| 屏幕会话 | 锁屏、电源菜单、分屏 | 无障碍全局动作 | 不确认关机/重启 |
| 音量 | 音量增大、音量减小、静音、取消静音 | Android AudioManager | 只控制媒体音量 |
| 媒体 | 播放/暂停、上一首、下一首 | Media KeyEvent | 不选择具体 App |
| 亮度 | 亮度增大、亮度减小 | Settings.System | 需要修改系统设置权限 |
| 设置入口 | Wi-Fi、蓝牙、飞行模式、网络、移动网络、热点、NFC、VPN | Android Settings Intent | 不直接开关受限系统能力 |
| 设置入口 | 定位、日期时间、语言、显示、声音与触感、通知、壁纸 | Android Settings Intent | 不选择具体值 |
| 设置入口 | 无障碍、应用管理、电池、存储、隐私、安全、勿扰 | Android Settings Intent | 不进行最终授权或确认 |
| App 启动 | 相机、微信、美团、支付宝、淘宝、抖音、QQ、电话、设置、浏览器、Chrome | Launcher Intent / 无障碍兜底 | 不做 App 内复杂任务 |

## 不属于 L1

这些任务进入 L2 或更高：

- 把时区改为阿根廷。
- 开启蓝牙并连接某个具体设备。
- 设置某张图片为壁纸。
- 修改声音与触感里的某个具体开关或滑杆。
- 微信发送消息、支付、下单、删除、确认提交。

## 下一步 L2 样板

L2 应该优先从系统设置 App 开始，因为它覆盖面广、风险可控、页面结构相对稳定：

1. 日期时间：进入时区页，搜索或选择目标时区，停在确认前。
2. 蓝牙：进入蓝牙页，开启入口或进入配对页，具体配对确认前停止。
3. 声音与触感：进入页面，定位铃声/媒体/震动区域，支持单项调节。
4. 壁纸：进入壁纸入口，停在选择来源页或预览页。
5. 显示：进入亮度、字体、深色模式、刷新率等子入口。
